# 🎲 Revolvium

The UI, 3D models, and audio for Revolvium, a 3D rotation-based puzzle game built with Unity and C#. You play as Irabel, who has to complete rotation puzzles to discover the artifacts left behind by a long lost civilisation. I worked on this as a team project, and this repo holds my part of it: the user interface, the 3D modelling, and the audio recording.

## 📦 Technologies

- `Unity`
- `C#`
- `Unity UI`
- `3D Modelling`
- `Audio Recording`

## ⚙️ Features

Here's what you can do in Revolvium's user interface:

- **Play with Keyboard or Controller**: The UI supports both input methods, so the on-screen prompts and navigation work whether you're using WASD or a gamepad.

- **Explore as Irabel**: Walk around with WASD or the left stick, interact with items you find using E or the west face button, and move the camera with the arrow keys or right stick.

- **Enter Rotation Mode**: Move the selector across the level, rotate it, and spin that piece of the level to solve the puzzle. Press Escape or the east face button to leave rotation mode.

- **Change Rotation Direction**: Switch the direction a piece rotates with Z and X on keyboard or the triggers on controller.

- **Animated Interface**: The UI is animated so it feels alive and responds to what you're doing.

### 🎯 Controls:

#### Keyboard

- **Walk**: WASD.
- **Interact**: E.
- **Move Camera**: Left and right arrow keys.
- **Move Selector**: A and D or W and S.
- **Rotate Selector**: Q and E.
- **Rotate Level Piece**: Space bar.
- **Leave Rotation Mode**: Escape.
- **Change Rotation Direction**: Z and X.

#### Controller

- **Walk**: Left stick.
- **Interact**: West face button.
- **Move Camera**: Right stick.
- **Move Selector**: D-pad.
- **Rotate Selector**: Bumpers.
- **Rotate Level Piece**: South face button.
- **Leave Rotation Mode**: East face button.
- **Change Rotation Direction**: Triggers.

## 🔨 The Process

On this project I was the UI designer and developer, the 3D modeller, and the audio recorder.

I started with the UI. I designed how the interface should look and feel, then built it in Unity with C#, so the game could be understood quickly by anyone picking it up. Since the game is meant to have simple controls, I wanted the UI to stay clear and never get in the way of the puzzles.

From there I added animation to the interface, so menus and feedback felt smooth instead of static. I also made sure the UI worked with both keyboard and controller input.

Next, I created 3D models for the game, which gave me a chance to work on the world that Irabel explores and not just the screens layered on top of it.

Finally, I recorded the audio for the game. Sound is a big part of how a game feels, so I wanted the interactions and the world to have audio that matched them.

All of this was done alongside the rest of the team, so it also meant making my work fit with everyone else's.

## 🚚 Running the Project

You can either play the downloadable build or run the project from source.

### 🎮 Play the Build

If you just want to play the game, download the build from the itch page:

1. Go to the [Revolvium itch page](https://jakeoreilly.itch.io/revolvium).
2. Download the build and extract it if it's zipped.
3. Run the game and start playing.

### 🛠️ Run from Source

To run the project in your local environment, follow these steps:

1. Clone the repository to your local machine.
2. Open Unity Hub and add the `Revolvium_Unity` folder as a project.
3. Open it with the Unity version listed in `Revolvium_Unity/ProjectSettings/ProjectVersion.txt`.
4. Open the main scene and press Play to try the game.
