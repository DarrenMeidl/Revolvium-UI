# REVOLVIUM
Join **Irabel** in our game, **REVOLVIUM**, where you will have to complete rotation based puzzles to discover the artifacts left by a long lost civilisation...

With simple controls and complex (yet understandable) level design, this game can be played by all.. although not all will enter the ruins and return to tell the tale of it's secrets.

### For keyboard:
# As Irabel
- Use the _WASD_ keys to walk
- Use _E_ to interact with items you find
# In Rotation Mode
- Use _A_ and _D_ to move the selector
- Use _W_ and _S_ to rotate the selector
- Use the _SPACE BAR_ to rotate that piece of the level
- Use _ESCAPE_ to leave rotation mode
- Use the _LEFT ARROW_ and _RIGHT ARROW_ to move the camera left and right
