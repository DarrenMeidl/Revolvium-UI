# REVOLVIUM
Join **Irabel** in our game, **REVOLVIUM**, where you will have to complete rotation based puzzles to discover the artifacts left by a long lost civilisation...

With simple controls and complex (yet understandable) level design, this game can be played by all.. although not all will enter the ruins and return to tell the tale of it's secrets.

### For Keyboard:
# As Irabel
- Use the _WASD_ keys to walk
- Use _E_ to interact with items you find
- Use the _ARROW KEYS_ to move the camera left and right
# In Rotation Mode
- Use _A_ and _D_ or _W_ and _S_ to move the selector
- Use _Q_ and _E_ to rotate the selector
- Use the _SPACE BAR_ to rotate that piece of the level
- Use _ESCAPE_ to leave rotation mode
- Use the _ARROW KEYS_ to move the camera left and right
- Use _Z_ and _X_ to change the rotation direction

### For Controller:
# As Irabel
- Use the _Left Stick_ keys to walk
- Use _West Face Button_ to interact with items you find
- Use the _Right Stick_ to move the camera left and right
# In Rotation Mode
- Use the _D-Pad_ to move the selector
- Use the _Bumpers_ to rotate the selector
- Use the _South Face Button_ to rotate that piece of the level
- Use _East Face Button_ to leave rotation mode
- Use the _Right Stick_ to move the camera left and right
- Use the _Triggers_ to change the rotation direction
