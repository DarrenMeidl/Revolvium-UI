# TERMINOLOGY

# TERMS
| Term | Definition |
| -- | -- |
| Level Core | Center of the level, typically (0, 0, 0), from where rotation is done around. Comes from an actual rubik's cube piece that holds the pieces together. (Note - not an actual piece in this game, rather just a concept) |
| Level Block | Piece of the level that is attached to the cube. Can be a cube or any other shape |
|  |  |
